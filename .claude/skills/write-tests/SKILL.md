# Написание тестов по стандарту AutoRepair

Источник истины — `src/docs/asciidoc/TESTING.md` (тип теста по слою, структура given/and/when/then/expect, `@Order`/`@Nested`
для комплексных сценариев, соглашения по AssertJ/Mockito). Перед написанием теста прочитать его целиком — не пересказывать
здесь, а следовать ему напрямую.

## Порядок действий

1. Прочитать `src/docs/asciidoc/TESTING.md`, если не читали в этой сессии или файл мог измениться.
2. Определить класс/слой, для которого нужен тест, и выбрать тип теста по таблице из документа.
3. Проверить, есть ли уже тесты для этого класса — не дублировать, расширять существующий тестовый класс, если тип теста совпадает.
4. Написать тест(ы) строго по структуре и соглашениям из документа.
5. Если для теста нужен testcontainers, а модуля ещё нет в `pom.xml` — не добавлять зависимость самовольно, сообщить об этом.
6. Запустить `./mvnw test -Dtest=ClassName#methodName` (Windows: `mvnw.cmd`) и убедиться, что тест проходит и падает при
   намеренной порче проверяемой логики (там, где это уместно проверить).
